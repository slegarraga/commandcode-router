# Support

Use GitHub Discussions for setup questions and model compatibility reports that are not confirmed bugs. Use Issues for reproducible defects and feature proposals.

Before asking for help, run:

```sh
commandcode-router doctor
commandcode-router status
```

Share the command output, operating system, Node version, Codex version, selected model slug, and the smallest safe reproduction. Remove capability URLs, API keys, authorization headers, prompts, file contents, and provider response bodies.

This volunteer project cannot provide an SLA. Command Code account, billing, entitlement, and upstream availability issues belong with Command Code support.
